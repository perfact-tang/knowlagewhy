
## Please carefully plan and execute the implementation based on the following requirements.

I want to build a "Knowledge Analysis & Research" system. I have an AI Agent harness base (`[https://github.com/SWE-agent/mini-swe-agent](https://github.com/SWE-agent/mini-swe-agent)`), and we will build it on top of this.

The problem I want to solve is as follows: Suppose I have a set of information, and I drag and drop it as a text file into my interface.

1. **First AI Agent (Knowledge Structure Parsing):**
Parses the content of the text file to extract its knowledge structure. It analyzes the article, stores the extracted structure in a Neo4j knowledge graph, and displays it on the screen.
2. **Second AI Agent (Related Information Research):**
Takes the key information extracted in step 1 and searches the internet for any other related information from the current timestamp looking back over the past three months. It then saves this new knowledge into the Neo4j knowledge graph and displays it on the screen.
3. **Third AI Agent (Fact-Checking & Source Tracing):**
Verifies the authenticity of the information by tracing its origin to see where it started. It stores the fact-checking/credibility data in the Neo4j knowledge graph and displays it on the screen.
4. **Fourth AI Agent (Virality & Substance Analysis):**
Investigates how the topic went viral/gained traction, determining whether there are real-world use cases/examples or if it is purely hype. It stores these findings in the Neo4j knowledge graph and displays them on the screen.
5. **Comprehensive Comparison & Final Graph:**
Once all this information is gathered and retrieved, perform a comprehensive comparison by combining all the collected Neo4j data. Generate the final unified Neo4j knowledge graph, store it, and display it on the screen.
6. **Final Animation Generation AI Agent:**
Using the final Neo4j knowledge graph, generate a comprehensive summary animation (handled by an AI Agent as well). I want a brief explainer video with Japanese voiceover.
